Os workshops de primeiros passos são introduções guiadas que ajudam você a explorar o GitHub Copilot sem precisar de um aplicativo existente ou de um cenário detalhado de desenvolvimento. Cada workshop começa de forma simples, apresenta o produto durante o uso e conduz você por um fluxo de trabalho completo.

Todos os workshops criam o mesmo Space Quiz a partir de uma pasta vazia. Assim, você pode escolher a ferramenta que deseja conhecer ou concluir mais de um para comparar como cada uma funciona.

> [!NOTE]
> Estes workshops foram criados por [James Montemagno][james] e adaptados de [First Steps with GitHub Copilot][source-lab], disponível sob a [licença MIT][source-license].

## Workshops

### [Tour do aplicativo GitHub Copilot][copilot-app]

Crie um Space Quiz colorido a partir de uma pasta vazia e percorra o ciclo de desenvolvimento: criar, aprimorar, testar, registrar instruções do projeto, publicar, planejar o trabalho, implementar issues, revisar e integrar um pull request, automatizar tarefas recorrentes e explorar uma extensão com Canvas.

### [Primeiros passos com o GitHub Copilot CLI][copilot-cli]

Aprenda o fluxo de trabalho com foco no terminal: crie o projeto e revise os diffs antes de gravá-los com o Git, execute sessões lado a lado em worktrees, planeje antes de editar e gerencie o contexto. Depois, crie, integre e delegue trabalho sem sair do shell.

### [Primeiros passos com o Visual Studio Code][vscode]

Use o fluxo de trabalho no editor: crie o projeto em um espaço de trabalho, aprimore elementos pelo navegador integrado, inspecione o contexto, teste antes de gravar com o Git, planeje antes de editar e use as ferramentas do GitHub para gerenciar issues, pull requests e sessões na nuvem sem sair do VS Code.
